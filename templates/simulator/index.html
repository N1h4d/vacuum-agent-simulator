PEAS Description of the Task Environment

P — Performance

Dirt cleaned +{{ scoring.dirt_cleaned|floatformat:0 }}, move {{ scoring.move_cost|floatformat:0 }}, collision {{ scoring.collision_penalty|floatformat:0 }}, SUCK on a clean cell {{ scoring.wasted_suck_penalty|floatformat:0 }}, all reachable dirt cleaned +{{ scoring.completion_bonus|floatformat:0 }}.

E — Environment

Grid world with clean/dirty cells and obstacles. Discrete, single-agent, deterministic, sequential, static (only the agent changes it). Partially observable in LOCAL sensor mode, fully observable in FULL mode.

A — Actuators

MOVE_UP MOVE_DOWN MOVE_LEFT MOVE_RIGHT SUCK STOP

S — Sensors

Own position, status of the current cell, the four neighbouring cells (clean / dirty / obstacle / wall). In FULL mode: the whole grid.
